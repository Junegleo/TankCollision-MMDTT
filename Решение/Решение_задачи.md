# Решение задачи

**Источник:** Методические указания по курсу «Математическое моделирование динамики твёрдого тела», раздел «Динамика материальной точки. Закон сохранения импульса», задачи для самостоятельного решения, **задача 3** (стр. 25).

**Условие.** Частица массой m₁ летит со скоростью V₁ вдоль оси OX. Частица массой m₂ летит со скоростью V₂ под углом α к оси OX. Частицы совершают абсолютно неупругий удар. Найти импульс системы после удара и выделившуюся при этом теплоту.

*Наша интерпретация для модели и мультика:* m₁ — бронебойный снаряд, m₂ — едущий танк; снаряд попадает в танк и застревает в броне.

---

## Дано

| | |
|---|---|
| m₁, V₁ | масса и скорость первой частицы (снаряда), V₁ ∥ OX |
| m₂, V₂ | масса и скорость второй частицы (танка) |
| α | угол между V₂ и осью OX |
| удар абсолютно неупругий | после удара частицы движутся как одно тело |

**Найти:** p (модуль и направление), Q.

## Рисунок

Перерисовать с файла `Рисунок.svg`:
- **а)** оси X, Y (вид сверху). Снаряд m₁ летит вдоль OX со скоростью V₁; танк m₂ в точке O, его скорость V₂ направлена под углом α к OX; пунктиром — скорость u общего тела после удара под углом β.
- **б)** треугольник импульсов: m₁V₁ + m₂V₂ = p.

---

## Решение

**1. Почему можно применить закон сохранения импульса.**
Рассмотрим систему «снаряд + танк». Во время удара на неё действуют внешние силы: тяжести, реакции опоры, сила тяги и трения гусениц. Все они **конечны**, а удар длится очень малое время Δt → 0, поэтому их импульс F·Δt пренебрежимо мал по сравнению с импульсами тел. Значит, на время удара систему можно считать **замкнутой**, и её импульс сохраняется.

Механическая энергия при этом **не сохраняется**: удар неупругий, часть кинетической энергии уходит на деформацию и нагрев (это и есть искомая теплота Q).

**2. Закон сохранения импульса (в векторной форме).**
После абсолютно неупругого удара тела движутся вместе со скоростью u:

  m₁V₁ + m₂V₂ = (m₁ + m₂)u = p    (1)

**3. Проекции на оси.**

  OX: pₓ = m₁V₁ + m₂V₂·cos α    (2)

  OY: p_y = m₂V₂·sin α        (3)

**4. Модуль импульса системы.**

  p = √(pₓ² + p_y²) = √((m₁V₁ + m₂V₂cos α)² + (m₂V₂sin α)²)

Раскроем скобки и учтём, что sin²α + cos²α = 1:

  **p = √(m₁²V₁² + m₂²V₂² + 2m₁m₂V₁V₂cos α)**    (4)

(это теорема косинусов для треугольника импульсов на рис. б).

**5. Направление импульса.** Угол β между p и осью OX:

  **tg β = p_y / pₓ = m₂V₂sin α / (m₁V₁ + m₂V₂cos α)**    (5)

Скорость тела после удара: **u = p / (m₁ + m₂)**, направлена так же, под углом β.

**6. Выделившаяся теплота** — это убыль кинетической энергии системы:

  Q = E_до − E_после

  E_до = m₁V₁²/2 + m₂V₂²/2

  E_после = (m₁ + m₂)u²/2 = p² / (2(m₁ + m₂))

  Q = m₁V₁²/2 + m₂V₂²/2 − p² / (2(m₁ + m₂))    (6)

**7. Упростим.** Приведём к общему знаменателю 2(m₁ + m₂) и подставим p² из (4):

  (m₁ + m₂)(m₁V₁² + m₂V₂²) − p² =
  = m₁²V₁² + m₁m₂V₂² + m₁m₂V₁² + m₂²V₂² − m₁²V₁² − m₂²V₂² − 2m₁m₂V₁V₂cos α =
  = m₁m₂(V₁² + V₂² − 2V₁V₂cos α)

Получаем:

  **Q = m₁m₂(V₁² + V₂² − 2V₁V₂cos α) / (2(m₁ + m₂))**    (7)

---

## Ответ

  **p = √(m₁²V₁² + m₂²V₂² + 2m₁m₂V₁V₂cos α),  tg β = m₂V₂sin α / (m₁V₁ + m₂V₂cos α)**

  **Q = m₁m₂(V₁² + V₂² − 2V₁V₂cos α) / (2(m₁ + m₂))**

---

## Проверка

**Размерность.** [p] = кг·м/с ✓. [Q] = кг·кг·(м/с)² / кг = кг·м²/с² = Дж ✓.

**Частные случаи.**
- α = 0 (снаряд догоняет танк): Q = m₁m₂(V₁ − V₂)² / (2(m₁ + m₂)). Если V₁ = V₂, то Q = 0 — тела «не ударились», логично ✓.
- α = 180° (лобовое столкновение): Q = m₁m₂(V₁ + V₂)² / (2(m₁ + m₂)) — максимум теплоты ✓.
- V₂ = 0 (танк стоит): p = m₁V₁, Q = m₁m₂V₁² / (2(m₁ + m₂)) — известная формула неупругого удара о покоящееся тело ✓.

**Физический смысл.** Выражение V₁² + V₂² − 2V₁V₂cos α = |V₁ − V₂|² — квадрат **относительной скорости** тел. Теплота определяется только относительной скоростью: Q = μ·v_отн²/2, где μ = m₁m₂/(m₁ + m₂) — приведённая масса.

---

## Численный пример (для модели)

Снаряд: m₁ = 7 кг, V₁ = 800 м/с. Танк: m₂ = 30 000 кг, V₂ = 10 м/с (36 км/ч), α = 60°.

| величина | расчёт | результат |
|---|---|---|
| pₓ | 7·800 + 30 000·10·0,5 | 155 600 кг·м/с |
| p_y | 30 000·10·0,866 | 259 808 кг·м/с |
| p | √(155 600² + 259 808²) | ≈ 3,03·10⁵ кг·м/с |
| β | arctg(259 808 / 155 600) | ≈ 59,1° (танк «увело» на 0,9°) |
| u | 302 839 / 30 007 | ≈ 10,09 м/с |
| E_до | 7·800²/2 + 30 000·10²/2 | 2 240 000 + 1 500 000 = 3,74 МДж |
| Q | по формуле (7) | **≈ 2,21 МДж** |

**Вывод:** Q составляет ≈ 98,7 % кинетической энергии снаряда — почти вся энергия снаряда переходит в тепло и деформацию брони. Именно поэтому броня в месте попадания раскаляется. А скорость танка из-за огромной массы почти не меняется (+0,09 м/с).

## Возможные вопросы преподавателя

1. **Почему импульс сохраняется, если на танк действуют сила тяжести, трение, сила тяги?**
   Эти силы конечны, а время удара ничтожно мало, поэтому их импульс за время удара пренебрежимо мал (см. п. 1).
2. **Почему нельзя применить закон сохранения механической энергии?**
   Удар абсолютно неупругий: часть энергии необратимо переходит во внутреннюю (тепло, деформация). Энергия сохраняется только полная: E_до = E_после + Q.
3. **Что значит «абсолютно неупругий удар»?**
   После удара тела движутся как единое целое с одной скоростью u.
4. **Когда теплота максимальна?**
   При α = 180° (лобовой удар): относительная скорость максимальна.
5. **Почему танк считаем материальной точкой?**
   Нас интересует только поступательное движение центра масс сразу после удара; вращение танка и размеры не учитываем, как сказано в условии («частицы»).
